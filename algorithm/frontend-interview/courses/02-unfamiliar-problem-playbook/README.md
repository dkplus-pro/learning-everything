# 02 遇到陌生算法题的解题思路

## 本课目标

陌生题最怕“脑子空白”。这一课给你一个可复用的破冰流程，让你即使没见过原题，也能从可验证的小步骤开始推进。

## 陌生题五步法

1. **复述题意**：用自己的话讲一遍，确认输入、输出、限制。
2. **缩小规模**：先用 3~5 个元素的例子手算，不要一上来想最优。
3. **列出动作**：题目允许你做什么？比较、交换、入栈、移动指针、选择/不选择？
4. **寻找结构**：
   - 成对匹配：考虑栈、哈希表。
   - 连续区间：考虑滑动窗口、前缀和。
   - 最优选择：考虑贪心或动态规划。
   - 图状关系：考虑 BFS/DFS。
5. **先拿分再优化**：先说出暴力解，再解释如何减少重复工作。

## 本课例题：有效括号

题目：判断只包含 `()[]{}` 的字符串是否括号匹配。

为什么适合作为陌生题入门？因为它体现了“最近打开的括号必须最先关闭”，这就是**后进先出**结构，也就是栈。

## 面试中卡住时可以这样说

> 我先不急着写代码。我观察到每个右括号都要和最近的左括号匹配，所以我需要一个能记录“最近未匹配左括号”的结构。栈符合这个特征，因此我尝试用栈推进。
