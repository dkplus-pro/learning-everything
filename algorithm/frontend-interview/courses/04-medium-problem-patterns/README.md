# 04 中等题通法：把暴力解优化成可复用模板

本课目标：掌握中等算法题最常见的升级路径——先写出暴力思路，再识别重复计算，最后套用滑动窗口、双指针、前缀和或单调结构。

## 中等题为什么难

中等题通常不是“不会写循环”，而是题目多了一个限制：

- 要在连续区间内求最优值。
- 要避免重复枚举所有组合。
- 要维护一个动态状态，并在状态非法时收缩范围。

## 四步通法

1. **先承认暴力解**：明确最直接做法，通常是 `O(n²)` 或更高。
2. **找重复工作**：观察哪些计算在相邻状态之间可以复用。
3. **选择模板**：连续子数组常看滑动窗口；有序数组常看双指针；区间和常看前缀和。
4. **定义收缩条件**：什么时候状态非法？非法时移动哪一个指针？

## 例题：无重复字符的最长子串

题目：给定字符串 `s`，找出不含重复字符的最长子串长度。

思路：右指针负责扩张窗口，`Map` 记录字符最后出现的位置；一旦发现重复字符，就把左指针跳到重复字符上次位置的右侧。

## 面试表达模板

> 我先用滑动窗口维护一个没有重复字符的区间。右指针每次加入一个字符；如果它在当前窗口内出现过，就把左指针移动到上次出现位置后一格。每一步更新最大长度。

## 复杂度

- 时间复杂度：`O(n)`，每个字符最多被左右指针处理一次。
- 空间复杂度：`O(k)`，`k` 是字符集大小。
