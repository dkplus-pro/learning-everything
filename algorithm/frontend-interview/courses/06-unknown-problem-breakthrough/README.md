# 06 不懂题破局：从复述题意到构造第一版答案

本课解决面试中最常见的卡点：题目没见过、听起来很抽象、短时间想不到标准套路。目标不是立刻完美，而是在 3 到 5 分钟内产出一个能沟通、能验证、能优化的方案。

## 学习目标

- 把陌生题翻译成输入、输出、约束、样例四件事。
- 用暴力解建立正确性锚点，再逐步寻找优化信号。
- 学会向面试官展示「我正在收敛问题」，而不是沉默卡住。

## 破局五问

1. **输出到底是什么？** 是数量、下标、路径、布尔值还是具体方案？
2. **数据规模多大？** 规模决定能不能暴力枚举。
3. **有没有顺序关系？** 有顺序就考虑双指针、栈、动态规划。
4. **有没有重复计算？** 有重复就考虑哈希表、记忆化、前缀和。
5. **能否先写判定？** 复杂构造题常常可以先写一个验证函数。

## 本课练习

Demo 用「最短无序连续子数组」模拟陌生题破局：

- 第一步：复述题意并写出最容易理解的排序对照法。
- 第二步：观察边界，只扩展必须被修正的区间。
- 第三步：把思路总结成面试表达。

运行：

```bash
npm run demo -- 06
```

## 面试表达模板

> 这个题我先用一个正确但可能不最优的方法确认目标：如果把数组排序，哪些位置发生变化就是必须修正的区间。接着我会观察能否不用完整排序，只通过左右边界和区间最大最小值优化。

### 独立 demo 脚本

```bash
npm run demo:06
```
