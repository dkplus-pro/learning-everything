# 01 从零建立算法题思维

## 本课目标

很多前端同学遇到算法题的第一反应是“我没背过”。本课先不追求高级套路，而是建立一个最小可用的解题流程：

1. **读题翻译**：把自然语言翻译成输入、输出、约束。
2. **手算样例**：用 1 个最小例子、1 个普通例子、1 个边界例子手算。
3. **先写暴力解**：即使不够优，也能让你说清楚思路。
4. **找重复工作**：优化通常来自“哪些计算被反复做了”。
5. **讲清复杂度**：用时间复杂度和空间复杂度证明你知道取舍。

## 面试回答模板

> 我先确认输入输出和边界；然后用一个小样例手算；如果暂时没有最优解，我会先写出暴力解保证正确，再观察是否有重复计算或可维护的状态，最后分析复杂度。

## 本课例题：买卖股票的最佳时机

题目：给定每天股票价格数组 `prices`，只能买一次、卖一次，且必须先买后卖，求最大利润。

- 输入：`number[] prices`
- 输出：最大利润 `number`
- 边界：空数组、只有一天、一直下跌时利润为 `0`

### 从暴力到状态维护

暴力思路会枚举每个买入日和卖出日，时间复杂度是 `O(n²)`。优化的关键是：当我们扫描到第 `i` 天时，只需要知道此前出现过的最低价格，就能计算“今天卖出”的最好利润。
