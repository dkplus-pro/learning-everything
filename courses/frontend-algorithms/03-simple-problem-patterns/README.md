# 03 简单题通法：把题目翻译成可检查的步骤

本课目标：让你面对简单算法题时，不再靠背答案，而是用一套固定流程把题目拆开、写出稳定代码。

## 适合题型

- 数组遍历与统计：最大值、计数、去重、两数之和。
- 字符串扫描：反转、字符频次、回文判断。
- 简单哈希表：记录“见过什么”、快速查找补数。

## 五步通法

1. **复述输入输出**：用自己的话说清楚函数接收什么、返回什么。
2. **手推 2 个例子**：一个普通例子，一个边界例子。
3. **选择最小工具**：能一次循环解决就不要上复杂结构；需要快速查找才使用 `Map` / `Set`。
4. **写循环不变量**：每次循环结束后，手里的变量代表什么。
5. **补边界检查**：空数组、重复值、大小写、找不到答案。

## 例题：两数之和

题目：给定整数数组 `nums` 和目标值 `target`，找出两个数的下标，使它们的和等于 `target`。

思路：从左到右扫描数组。当前数字是 `x`，如果之前见过 `target - x`，就找到了答案；否则把当前数字和下标记下来。

## 练习建议

- 先在纸上写出“当前值、需要的补数、哈希表内容”。
- 写代码时先保证正确，再讨论时间复杂度。
- 每道简单题都按五步流程复盘一次，训练稳定性。

## 复杂度

- 时间复杂度：`O(n)`，每个元素最多访问一次。
- 空间复杂度：`O(n)`，最坏情况下需要记录所有已经扫描过的数字。
